# Game logos

Two ways to add a logo:

1. **Admin dashboard (easiest):** Games -> Edit -> drop an image on the logo box.
   It's cropped to a square, resized to 256x256 and stored with the game.
2. **Files in this folder:** add `<game-id>.png` here (e.g. `ghorde1.png`) and
   commit. The starter games already point at these filenames:

   find-the-target.png, piano-tiles.png, virus-snake.png, ghorde1.png,
   meteor-mayhem.png, singularity-drive.png, warpscythe.png

Square images, at least 256x256, look best. If a logo is missing, the site
shows a generated monogram instead.
